## 🚀 How to Use Any Extension

1. Download or clone this repository
2. Open the extension folder in **VS Code** with the AL Language extension installed
3. Update `.vscode/launch.json` with your tenant ID and environment name
4. Press **Ctrl + F5** to publish to your sandbox

Each folder has its own `README.md` with full deployment steps.
